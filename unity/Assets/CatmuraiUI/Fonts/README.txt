Fonts for the Catmurai UI. All from Google Fonts, SIL Open Font License 1.1 (see OFL_*.txt):
- Knewave (big brush titles, e.g. PAUSED / OPTIONS / counters)
- Kaushan Script (menu buttons, toasts, setting labels)
- Cinzel (small-caps labels, section headers, footer)
- Cormorant Garamond (body / descriptions)
UI art in ../Art: ui_logo.png and ui_start_button.png are cut from Lisvi Senpai's Catmurai UI reference sheet;
everything else is procedurally painted.
